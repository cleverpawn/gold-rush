# Changelog — Dungeon Match · Muse Edition

All notable changes to Dungeon Match — Muse Edition are documented here.
Versions follow Semantic Versioning (MAJOR.MINOR.PATCH). While the game is
in development, versions stay in the 0.x.y range. Development milestone IDs
(e.g. 1H.1) are internal work references and are separate from release
version numbers. See RELEASING.md for the versioning rules and the release
checklist.

## [v0.1.0] — 2026-10-29 — Combat Prototype

First official development release: a stable, playable combat prototype.

### Included systems

- Six selectable heroes with individual starting HP and working passive abilities
- Responsive six-character selection screen
- 8×8 match-3 board
- Sword, Shield, Heart, and Soul tile effects
- Touch dragging and tap swapping
- Match detection, gravity, refill, and cascades
- Solo and Duo enemy combat
- Enemy targeting and attack intentions
- Block, healing, Soul Charge, Victory, and Defeat
- Normal Adventure and Legacy Test starting-state configurations
- Experimental Gold tile modes A, B, and C
- Experimental Gold accumulation (dev-only currency prototype)
- Separate desktop and mobile animation profiles
- Mobile rendering optimization
- Board-first responsive battle layout
- iPhone safe-area correction for home-screen launches

### Known unfinished systems

- Soul Burst is displayed but inactive
- Special match power-ups are not implemented
- Gold currency is experimental and not permanently adopted; there is no spending, shop, or merchant system
- Dungeon exploration is not implemented
- Camping, supplies, merchants, equipment, upgrades, leveling, and story progression are not implemented
